# Pragati Sharma — Portfolio

A premium, responsive personal portfolio built with **HTML, CSS and vanilla JavaScript**.

## Features
- Animated hero section
- Your profile photo included
- Scroll reveal animations
- Scroll progress bar
- Back-to-top button
- Dark/light mode with localStorage
- Responsive mobile navigation
- Animated statistics
- Project cards and research section
- Hover effects and glassmorphism
- No framework or build step required

## Folder structure
```text
pragati-portfolio/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── pragati-profile.webp
│   └── Pragati-Sharma-Resume.pdf   # add your PDF here if desired
└── README.md
```

## Run locally
Just open `index.html` in your browser.

For the best local development experience, use VS Code + Live Server.

## Deploy
This is a static website, so it can be deployed directly to GitHub Pages, Vercel, Netlify, etc.

Before deployment:
1. Add your PDF as `assets/Pragati-Sharma-Resume.pdf`.
2. Replace the Google Scholar placeholder if you have your exact profile URL.
3. Update any project/demo URLs you want to feature.
